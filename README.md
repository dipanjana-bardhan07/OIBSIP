# Oasis Infobyte - Python Programming Internship (OIBSIP)

Welcome to my official repository for the Oasis Infobyte Python Programming internship track. This repository contains the source code for all the completed internship tasks.

## 🚀 Tasks Implemented

### 1. Task 2: BMI Calculator
- **File:** `bmi_calculator.py`
- **Description:** A CLI-based tool that calculates Body Mass Index based on user input (weight & height) with built-in input validation and health status classification.

### 2. Task 3: Random Password Generator
- **File:** `password_generator.py`
- **Description:** A customizable security utility that generates strong, randomized passwords enforcing length constraints and character-type variety.

### 3. Task 6: Basic Weather App
- **File:** `weather_app.py`
- **Description:** A functional weather script utilizing the OpenWeatherMap API pipeline to deliver live atmospheric metrics for searched locations.
